# Production rollout — 2026-10-28: доработки кабинета (14 пунктов)

Коммит `d8de1c3` (ветка `feat/evaluation-v2`), задеплоено на `https://aidermy.ru`.

## 1. Что изменено

| # | Проблема | Решение |
|---|---|---|
| 1 | «Продукт больше недоступен в каталоге» при открытии отчёта из уведомления | Продукт сохраняется в каталог ДО открытия карточки: `ScanPage.continueFromPreview` вызывает `POST /api/products/create` для сканирования/ручного ввода/состава (не только для импорта по ссылке). Дополнительно клиент умеет открыть продукт по id: новый `GET /api/products/by-id/{id}` + `api.productById`. |
| 2 | Нет возврата из предпоказа нового продукта | В предпоказе кнопка «← Выбрать способ» (`backToMethods`) сбрасывает фазу/фото/результат; после «Продолжить анализ» вкладка сканирования перезапускается (`key={scan-${scanSession}}`) и открывается с выбора способа. |
| 3 | В уведомлениях названия продуктов | Заголовок формируется на клиенте и на сервере: «Проверка средства от 28.10.2026, 19:10» / «Проверка набора от …». Добавлены превью: `user_notifications.image_urls` (1 для средства, до 4 для набора), в теле уведомления — только вердикт/оценка. |
| 4 | Устаревший статус проверки, нет «проверяется» | `onChecked` сразу помечает карточку `check.status="checked"` и запоминает время; `enrichCheckStatuses` не откатывает только что проверенный продукт в «не проверено/устарело» в течение 2 минут. В карточках продуктов, на полке и в профиле добавлен статус «Проверяется» с анимацией `loading-dots` (как у наборов). В профиле появился блок «Статус средств на полке» (счётчики + список). |
| 5 | Поиск в каталоге «сбрасывался», пустой результат, автокомплит | Список при активном поиске строится только из серверных результатов (без локальной подфильтрации, которая давала «прыжок»); состояние строки поиска не затирается внешним query; пустой результат — пустой каталог с текстом запроса. Ранжирование ужесточено: значимые токены запроса должны подтверждаться (dual barrier: 63 → 8 релевантных, celimax: 69 → 54, «zzzqqqxxx» → 0). Под полем — автокомплит только словами (бренды и названия), без карточек. |
| 6 | Пакетный анализ | Кнопка и вся клиентская логика (quote, запуск, поллинг, сообщения) удалены; серверный эндпоинт `batch/quote` оставлен (покрыт тестом). |
| 7 | Сортировка по категориям на полке | Средства снова сгруппированы по категориям с заголовками и счётчиком. |
| 8 | Реальные лимиты тарифа | Полка уже ограничивалась на сервере (5/10/15). Добавлен лимит наборов: `compatibility_set_limit` = 2/5/10, проверка в `POST /tasks/compatibility` (409 с понятным текстом), UI блокирует запуск при достижении лимита и показывает подсказку. |
| 9 | Иконка баллов в наборе | `coins` заменена на принятую `credits` (как в шапке), цвет иконки и рамки — фиолетовый акцент. |
| 10 | Автоподбор продукта | Кнопка «Автоподбор продукта» и переход в режим `auto` скрыты (временно), код оставлен для быстрого возврата. |
| 11 | Зелёный → фиолетовый | Введён токен `--accent: #7c3aed` (`--accent-strong`, `--accent-soft`, `--accent-border`). На акцент переведены иконка баллов, ссылки, выделение, прогресс полки, дропзоны, `evalv2 --green` и т.п. Семантические цвета вердиктов (зелёный/жёлтый/красный) сохранены. |
| 12 | Цвет вердиктов | Добавлены `verdictClass()` и классы `.verdict-text--good/warn/bad/neutral`; вердикты окрашены на полке, в карточках, в наборах, в отчёте набора (включая секции «что оставить / что изменить»). |
| 13 | Подтверждение удаления за карточкой | Найдена причина: `.drawer { z-index: 1301 !important }` при `.modal-backdrop` 100. Общий слой модалок поднят до 1400, подтверждение — 1500 (проверено через `elementFromPoint`). |
| 14 | Медленные повторные картинки | Превью `/api/images/thumb` отдаются с `Cache-Control: public, max-age=31536000, immutable` (+ETag/Last-Modified): браузерная копия не перезапрашивается. |

## 3. Ограничения / что осталось

- «Проверяется» показывается при локальной проверке и при серверных статусах
  `queued/running`; отдельного статуса в Evaluation V2 для промежуточных фаз нет.
- Лимит наборов считается по невизуальным (не удалённым) наборам; старые наборы
  сверх нового лимита не удаляются, но новый набор создать нельзя до удаления старого.
- Серверный `POST /api/v1/compatibility/batch/quote` и UI-режим автоподбора оставлены
  в коде — они скрыты, а не удалены (по формулировке «временно убрать»).
- Фиолетовый акцент выбран `#7c3aed` (ближайший к используемому в проекте `#a855f7`,
  но с достаточным контрастом для текста и иконок). При необходимости меняется одной
  переменной `--accent` в `src/index.css`.
