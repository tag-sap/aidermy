### Реализация Phase 1
- `backend/app/phase1.py`: `PHASE1_VERSION = "2.0.0"`.
- Для каждой оси из `AXES` профильный multiplier ограничивается диапазоном [1, 2].
- При multiplier <= 1.0 ось не блокирует и threshold равен `None`; при multiplier > 1.0 threshold = `2.0 - multiplier`.
- Блокировка возникает, если отрицательная нагрузка строго больше активного порога.
- Профильный multiplier используется для выбора блокирующей оси/порога, но не должен повторно масштабировать величину отрицательных вкладов ингредиентов и взаимодействий.
- При `blocked` обычный score Phase 2 остаётся `None`; положительные факторы не должны компенсировать блокирующую нагрузку.
- Эта схема является реализованной технической логикой, но не клинически откалиброванной моделью. Независимая калибровка остаётся отдельной задачей.
