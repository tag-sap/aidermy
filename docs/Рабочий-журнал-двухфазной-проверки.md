## 2026-10-13 (Этап 1) — Исправление зависания проверки

### Подтверждённая причина
V2 frontend `ProductDrawer.check()`: при `score: null` (blocked/insufficient_data) обработчик выполнял `setPhase("idle"); return` БЕЗ вызова `onChecked` → `checkingIds` не очищался → карточка вечно показывала «Проверяем…». Аналогично в `catch` не очищался `checkingIds`. Статус blocked/insufficient терялся (drawer сбрасывался в idle).

### Исправление
- `src/App.tsx`: `check()` переписан — `finally { onCheckFinished(product.id) }` гарантирует снятие loading; ветки `Не рекомендовано` / `Недостаточно данных` / `passed` обрабатываются явно; `onChecked` принимает `score: number | null` и `recommendationStatus`.
- `src/data.ts`: `Match.score` → `number | null`.

## 2026-10-13 (Этап 2) — База знаний категорий для LLM
