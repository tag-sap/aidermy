## 2026-10-19 — Knowledge Graph: замещение взаимодействий (interaction replacement v1.0.0)

**Задача:** довести Knowledge Graph взаимодействий ингредиентов до production в реальном scoring pipeline Aidermy, не создавая параллельную систему скоринга.

### Принятое правило
- Подтверждённая пара замещает индивидуальные эффекты обоих ингредиентов **только на своей оси**; на остальных осях индивидуальные эффекты сохраняются.
- Замещение не суммируется с индивидуальными эффектами на той же оси (нет двойного учёта).
- `effect_kind='absolute'` — `strength` записи является полным совместным эффектом пары. `effect_kind='delta'` (изменение относительно индивидуальных эффектов) к замещению **не допускается**: восстановить полный эффект из неё нельзя.
- Допуск: `state=known` (confidence >= `DEFAULT_CONFIDENCE_THRESHOLD` = 0.5), непустые `evidence` и `source`, `source_type` из подтверждённых (`pubmed`, `clinical`, `clinical_trial`, `regulatory`, `in_vitro`, `literature`, `expert_review`, `label`). Эвристики/AI/пустой источник отклоняются.
- Конфликты: согласованные дубли пары+оси схлопываются (max confidence, затем max id); противоречивые — отклоняются (`conflicting_records`); два взаимодействия с общим ингредиентом на одной оси — отклоняются (`shared_ingredient`). Порядок записей не влияет на результат.

### Исходное состояние (аудит)
